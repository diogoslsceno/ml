# 🐍 Machine Learning com Python & Jupyter Notebooks

Repositório dedicado ao estudo prático, desenvolvimento de modelos de Machine Learning, análise estatística de dados e atividades de fixação (microlearning) em Python.

---

## 📌 Conteúdo do Repositório

### 📚 Módulos de Aulas (`aulas/`)
- **Aula 01**: Introdução ao Aprendizado Supervisionado (KNN) e Tratamento de Dados Ausentes.
- **Aula 02**: Análise Exploratória, Pré-processamento, Escalonamento de Atributos, Árvores de Decisão, Random Forest, Naive Bayes, SVM e Regressão Logística.
- **Aula 03**: Aprendizado Não Supervisionado e Agrupamento (Clustering) com K-Means.
- **Aula 05**: Introdução a Redes Neurais, Deep Learning (Keras/TensorFlow) e Processamento de Linguagem Natural (PLN).
- **Aula 06**: Tópicos Avançados, Métricas de Avaliação de Desempenho e Construção de Pipelines.

### 🛠️ Oficinas Práticas (`oficinas/`)
- **Oficina 02.1**: Regressão Linear/Múltipla para análise de dados de automóveis (`car_data.csv`).
- **Oficina 03.2**: Segmentação de Clientes com K-Means (`Mall_Customers.csv`).
- **Oficina 05.2**: Redes Neurais e Deep Learning com TensorFlow.
- **Oficina 05.3**: Processamento de Linguagem Natural (PLN) aplicado.

---

## 🧰 Principais Bibliotecas Utilizadas
- **Análise & Manipulação de Dados**: `pandas`, `numpy`
- **Visualização**: `matplotlib`, `seaborn`
- **Machine Learning Clássico**: `scikit-learn`
- **Deep Learning**: `tensorflow`, `keras`
